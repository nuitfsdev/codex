# Weekly Research Shortlist — 2026-W37

Project: 3D Scene Understanding with 2D Vision-Language Models via Abstract 3D Representations and Viewpoint Alignment
Updated: 2026-09-12

## Ranking

### 1. SAFER-QA / QASER + CRG — QA-utility-aware support selection with constraint-first global candidate generation
**Current best candidate.**

Pipeline:
`question -> seed hypotheses -> relation/question-type parser -> constraint-first candidate generation over the appropriate global set -> QA-support budget allocation -> PoseAlign-T directional refinement -> selective Abstract-3D rendering -> <=7B VLM`

Key change this week: do **not** use generic KNN/radius or hard semantic Top-K as the primary candidate gate. Official AgentGrounder code uses vector-store semantic retrieval with `k=5` before spatial tools, which can discard an answer/support object whose label/description is weakly similar to the question. Relation intent should choose the search operator first; geometry then verifies candidates, and semantic/diversity scores only reduce the surviving set to the render budget.

Scores (1-5): Novelty 3.6 integrated; Expected Accuracy Gain 3.8; Feasibility 4.7; Compute Cost 4.9 (higher=cheaper); Fit 5.0; Evidence Strength 4.6.
Object-selection targets: Object Reduction Ratio 50-85%; Question Entity Coverage >=95%; Supporting-Context Retention proxy-only; context-loss risk medium-low relative to semantic-TopK-first.

Matched-budget ablation:
`Full Scene` vs `GraFT/seed-only` vs `AgentGrounder-style semantic Top-5 first` vs `Seed+KNN` vs `Seed+radius` vs `CAPruner endpoints` vs `PruneGround-style visual anchors` vs `CRG constraint-first` vs `CRG + support-budget allocation` vs `+PoseAlign-T`.

## Strong baselines / novelty limiters
- **CAPruner (ACL 2026):** relation/edge pruning; useful baseline or support-candidate generator, not sufficient as QA object selector.
- **PruneGround (2026-06-30, public code):** frozen-VLM spatial pruning and visual-anchor expansion; major novelty limiter for generic unnamed-object discovery.
- **AgentGrounder (2026-05-25, public code):** zero-shot selective retrieval + geometric tools + on-demand rendering; official retrieval hard-caps semantic vector search at Top-5, making it a strong baseline for testing semantic-first failure modes.
- **GraFT (2026-09-03):** training-free selective rendering/retrieval; near-task baseline.
- **SeGPruner:** direct ScanQA evidence for semantic saliency + geometry/diversity under aggressive token budgets.
- **CoV (Findings ACL 2026):** strong training-free question-aligned view-selection baseline on ScanQA/SQA3D.
- **IVSGround (ECCV 2026):** learned query-conditioned influential view selector; reinforces that view selection should be secondary/ablation rather than the main novelty.

## Weekly conclusion
The week's most important design correction is:

**Question/relation semantics should determine the candidate search space; geometry should verify it. Geometry or semantic similarity should not universally determine the search space.**

This avoids two failure modes:
1. KNN/radius drops valid distant objects for global/opposite/functional relations.
2. semantic Top-K drops unnamed answer/support objects whose category is absent from the question.

The top candidate remains SAFER-QA/QASER, now instantiated with CRG constraint-first candidate generation before support-budget allocation and PoseAlign-T.
