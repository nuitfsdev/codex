# Weekly Research Shortlist — 2026-W38

Project: 3D Scene Understanding with 2D Vision-Language Models via Abstract 3D Representations and Viewpoint Alignment
Updated: 2026-09-17

## Ranking

### 1. SAFER-QA / QASER-CF — Constraint-first QA-specific evidence retention
**Current top candidate.**

Pipeline:
`question -> seed hypotheses -> relation/question-type parser -> constraint-first global candidate generation -> QA-support evidence allocation -> PoseAlign-T -> selective Abstract3D rendering -> <=7B VLM`

Key thesis claim: select the minimal/compact object subset that preserves QA evidence, including unnamed supporting/context objects, **before rendering**. Do not use generic semantic Top-K, KNN or radius as an early universal gate.

Scores (1-5; Compute Cost higher=cheaper): Novelty 3.5; Expected Accuracy Gain 3.8; Feasibility 4.7; Compute Cost 4.9; Fit 5.0; Evidence Strength 4.7.
Targets: ORR 50-85%; QEC >=95%; SCR high under matched object budget; context-loss risk medium with fallback expansion.

### 2. QASER-Div — diversity-reserved support allocation
After QASER-CF global candidate generation, reserve part of the object budget for distinct supporting hypotheses using frozen feature-space diversity (DPP or greedy diversity), while hard-retaining seeds and relation-conditioned candidates. Motivated by 3DZip/CoVeR evidence that relevance-only or spatial-only compression can lose coverage. This is an integrated refinement, not a standalone headline contribution.

Scores: Novelty 3.2 standalone / 3.7 integrated; Expected Gain 3.7; Feasibility 4.8; Compute Cost 4.9; Fit 5.0; Evidence 4.8.

### 3. UGSE — Uncertainty-Gated Support Expansion
Adaptive object budget: start with the compact QASER-CF set, expand support only if evidence is ambiguous/missing/conflicting. Useful refinement but iterative VLM calls can increase inference cost.

Scores: Novelty 3.0 standalone / 3.4 integrated; Expected Gain 3.5; Feasibility 4.2; Compute Cost 3.6; Fit 4.8; Evidence 4.2.

### 4. OLEA — Object-Level Evidence Allocation
SeGPruner-inspired relation/semantic saliency plus geometric diversity under an object budget, transferred from token pruning to pre-render object selection.

Scores: Novelty 3.0 standalone / 3.5 integrated; Expected Gain 3.5; Feasibility 4.7; Compute Cost 4.8; Fit 5.0; Evidence 4.6.

## First-tier baselines / novelty limiters
- **GraFT (2026-09-03):** training-free; direct ScanQA evaluation; compact 3DSG with symbolic geometry, allocentric BEV and task-relevant egocentric visual grounding. Limits novelty of generic `scene graph + tools + task-relevant views`.
- **CAPruner (ACL 2026):** peer-reviewed relation/edge pruning baseline and possible support-candidate generator; not a complete QA object selector.
- **PruneGround (2026-06-30):** frozen-VLM language-guided spatial pruning and visual-anchor expansion; major novelty limiter for generic pruning/unnamed-anchor discovery, but objective is 3D grounding rather than open-ended QA evidence retention.
- **AgentGrounder (2026-05-25):** semantic-first retrieval + geometry baseline; useful to test early semantic hard-gate failures.
- **SeGPruner:** direct ScanQA evidence that semantic saliency plus geometric coverage can preserve performance under aggressive token reduction.
- **3DZip (ECCV 2026):** training-free; code public; ScanQA/SQA3D/OpenEQA. Feature-DPP + spatially constrained merging; strong evidence that feature diversity/object coverage matters under a strict token budget. Token-level, not an object selector.
- **CoVeR (2026-09-08 preprint):** training-free deterministic spatial-coverage token pruning on ScanQA/SQA3D/OpenEQA. Token-level novelty limiter for generic coverage-aware pruning.
- **CoV / IVSGround:** view-selection baselines; view selection should remain secondary, not the main novelty.

## Matched-budget ablation priority
`Full Scene` vs `GraFT near-task baseline` vs `semantic Top-K` vs `Seed+KNN` vs `Seed+radius` vs `CAPruner endpoints` vs `PruneGround-style expansion` vs `QASER-CF relevance-only` vs `QASER-CF + spatial coverage reserve` vs `QASER-Div feature-diversity reserve` vs `+PoseAlign-T`.

## Weekly conclusion so far
SAFER-QA / QASER-CF remains #1. 3DZip and CoVeR raise the novelty bar for generic diversity/coverage pruning, but also strengthen the empirical motivation for selective evidence budgets. The defensible gap remains **QA-specific object/subscene evidence retention before rendering, under a strict object/render budget, with explicit retention of unnamed supporting evidence**. QASER-Div is currently the strongest budget-allocation refinement because it avoids assuming that answer/support objects are nearest to seeds or highest in semantic Top-K while remaining training-free.
