## 2026-10-24 evidence update

At K=12 Parent Acc 56.4%, Hit@K 79.0%, Recall@K 70.7%; Sub-Rerank Hit 82.4/Recall 74.3 but Acc only 53.4%. Video QA, not 3D QA: supports **distractor-aware** evaluation, not direct accuracy transfer. EMNLP 2026 author claim; soft perspective predicates and symbolic execution already prior art. Full repo requires >=3 GPUs, but fixed-box predicate subset is a feasible CPU ablation; no new 3D perception.

## 2026-10-25 evidence update (Sunday; latest arXiv batch Friday 23 Oct)
- **SpatialMem v3** (revised **22 Oct 2026**, https://arxiv.org/abs/2601.14895): material new evaluation on VSI-Bench, OpenEQA and 12 annotated ScanNet scenes. Anchor-first walls/doors/windows hierarchy and linked evidence retrieval are **prior art**; the work is NOT ScanQA/SQA3D and requires offline RGB reconstruction. OpenEQA same-answerer K=8 frame retrieval 62.0 vs uniform 61.6; text-only serialized memory 35.1 vs blind 44.5; K=2 retrieval 52.7 vs uniform 50.0. ScanNet structural-parent assignment is useful, but its RGB-only instance SR@0.5=0.18 vs privileged ConceptGraphs 0.41. Author claims code/data, public official repo not independently verified.
- **ViewMind3D** (30 Jul 2026, https://arxiv.org/abs/2607.28442), previously missed directly relevant training-free ScanQA/SQA3D method: question-view selection + guided detection + GLOBAL BEV + multi-agent QA; o3 ScanQA CIDEr 73.41, SQA3D EM 50.75. Uses proprietary models, ~90k tokens and ~120s/query, no verified official code, not <=7B local or strict selected-object-only. GPT-4.1 ablation: guided detection helps overall SQA3D 47.07->48.64 but hurts How 47.31->39.78. Question-type-specific evidence routing is worth testing, not novel alone.
- **Chat-Scene++** (IEEE TPAMI, published 31 Mar 2026; https://doi.org/10.1109/TPAMI.2026.3679561 ; code https://github.com/Collab-Gen/Chat-Scene): context-rich object sequences, ID tokens and grounded CoT already prior art. Vicuna-7B/LoRA and 3D training; do not call full method training-free.
- New refinement **Anchor-Path Witness Budget (APWB)** for existing annotated structural references only. Trigger only for structural/multi-hop QA, retain named seeds + unnamed answer candidates + required wall/door/window anchor path before rendering under strict K. No extra detection/segmentation; if anchor absent from fixed annotations, mark unsupported. CPU/training-free V0. Risks structural questions sparse and anchors absent; HIGH context loss K=5. Scores N2.5 G3.1 F4.4 C4.7 Fit4.7 E3.8. Keep below core Role-Aware and DWB pending question-type audit.
- Secondary **Typed Evidence-Channel Gate**: choose selected-render vs symbolic box facts by QA type, evaluation-only. Scores N1.9 G3.0 F4.7 C4.8 Fit4.7 E4.3. Do not conflate annotation-only reasoning with visual improvement.
- **Current top still SAFER-QA/QASER-PreRender.** Main next test unchanged: SemanticTopK vs OpenSlotSoft vs Role-Aware Witness Coverage at K=10,M=1, same <=7B VLM, prompt, calls and renderer. CPU-only prevalence audit + 50-100 independently annotated supporting-witness examples first. No GPU benchmark, no secrets. Full notes: research/daily/2026-10-25.md.
