## 2026-10-24 evidence update
- New 2026-10-22 arXiv (listed 23-Oct): Retrieval-Augmented Online Textual Memory for Episodic Memory Video QA, https://arxiv.org/abs/2610.31284 . At K=12 Parent Acc 56.4%, Hit@K 79.0%, Recall@K 70.7%; Sub-Rerank Hit 82.4/Recall 74.3 but Acc only 53.4%. Video QA, not 3D QA: supports **distractor-aware** evaluation, not direct accuracy transfer. Original descriptor Qwen3-VL-8B + Gemini 2.5 Flash; no official code confirmed.
- New 2026-10-22 arXiv: ReCoG https://arxiv.org/abs/2610.31282 ; NeurIPS 2026 claim on project https://csy-98.github.io/ReCoG/ ; training-free relational concept graph for confusable object candidates, but different task. Project code link returned 404; no reproducible code verified.
- Previously missed high-impact spatial prior: SATURN https://arxiv.org/abs/2606.22694 , code https://github.com/HLR/SATURN and 3D-FoRCE dataset. EMNLP 2026 author claim; soft perspective predicates and symbolic execution already prior art. Full repo requires >=3 GPUs, but fixed-box predicate subset is a feasible CPU ablation; no new 3D perception.
- Vantage https://arxiv.org/abs/2610.11810 has official code https://github.com/q1xiangchen/Vantage ; training-free seek-and-view with 3D foundation model, only view-planning baseline. No main-method full-scene render.
- New refinement **Discriminative Witness Budget**: retain complete seed–unnamed-answer–support bundles, penalize redundant/misleading distractors at fixed K. Track Answer-Witness Recall AND downstream QA; higher support recall need not mean higher accuracy. Context-loss HIGH at K=5. Training-free CPU V0; no measured gain. Scores N2.9 G3.5 F4.6 C4.7 Fit5.0 E3.7.
- Secondary ablation **SATURN-Lite**: frame-aware soft box predicates on selected objects, N1.8 G3.1 F4.8 C4.9 Fit4.7 E4.4. Full SATURN is not a fit; do not claim soft predicates as novelty.
- No GPU benchmark. Continue K=10,M=1 matched-VLM SemanticTopK vs OpenSlotSoft vs Role-Aware Witness Coverage first, then DWB; box-only/support-removal controls and independent support labels essential. Weekly top remains SAFER-QA / QASER-PreRender, conditional on matched-budget QA gain.
