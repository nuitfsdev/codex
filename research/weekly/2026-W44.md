## Object-selection rules and safeguards
- Parse explicit **named seeds** separately from **unnamed answer/support/context objects**. Do not require exact noun match for unnamed answer slots. Search ALL annotated objects via cached semantic representations and CPU geometry; render ONLY selected K.
- Retain plausible answer endpoints, relation witnesses, same-class disambiguators, competing candidates and frame/structural anchors only when needed. Do not use nearest-neighbor distance as a universal hard gate.
- Relation-specific soft geometry must be evaluated in an appropriate pose/reference frame; uncertain frames -> keep alternatives. Counting/existence/negative questions require completeness/abstention handling; box-only answers must be identified as symbolic/metadata-only, not visual reasoning.
- Report ORR=1-|S|/N, QEC (named-seed coverage), Answer-Witness Recall, Supporting-Context Retention (independent GT required; otherwise PROXY), Complete-Witness Coverage, Distractor Density, Context-Loss Rate, QA accuracy, latency and VRAM.
- ORR 50-85%, QEC>=95% are UNVERIFIED targets. Context-loss risk HIGH K=5, MEDIUM/HIGH K=10 for relational questions, higher for counting. Independent manual supporting-object annotation is missing; build 50-100 held-out validation examples before treating SCR as a true GT metric.

## 27 Oct addendum — verified code, benchmark and candidate refinement
**Freshness:** official arXiv cs.CV /new still listed **Monday 26 Oct** at scan time; no verified new 27 Oct batch. Full daily: [2026-10-27.md](../daily/2026-10-27.md). No GPU benchmark.

**PROVE** (arXiv:2610.32440, submitted 23 Oct; surfaced 26 Oct) https://arxiv.org/abs/2610.32440 ; **official code verified** https://github.com/mayank05942/PROVE ; WACV 2027 acceptance stated by authors and repository (proceedings not independently checked). Frozen CLIP ViT-B/16 + **trained** lightweight evidential Beta head; outputs patch relevance, vacuity and absent-referent signal. Not training-free as a whole. No ScanQA/SQA3D; original GPU VRAM unreported. Strong prior for uncertainty/absence verification, **not** pre-render selection. A missing object in a partial render must never be equated with global scene absence.

**MV-ScanQA / TripAlign / LEGO** (ACM MM 2025, DOI 10.1145/3746027.3758244): https://arxiv.org/abs/2508.11058 ; official dataset/project https://matthewdm0816.github.io/tripalign-mvscanqa/ ; code https://github.com/matthewdm0816/MVScanQA . ~10K compositional QA; 68% require >=2 original views, 13% >=3 (IoSA-based solvability, **not** occlusion-proof). TripAlign has 1M view/object-set/text triplets. Strong **prior art** for multi-object and multi-view alignment; useful benchmark, but source “related objects” are NOT certified complete supporting-object GT. Original LEGO training is heavy (4–8 GPUs around 40GB and 150–300GB RAM per README), so transfer dataset/protocol only, not architecture. Dataset download/schema not yet validated. Official repo DATA.md includes scene-view-object IoSA computation.

**New integrated refinement (rank after RWC): View-Complete Witness Allocation (VCWA).** Jointly select named seeds, scene-wide unnamed answer/bridge/support witness bundles and M views under **union |S|<=K**, without full-scene rendering; allow different views to show different witness objects. Optional occlusion-aware visibility on selected meshes. Proposed only, not measured. Scores N2.6 Gain3.4 Feasibility4.2 Compute4.3 Fit4.9 Evidence4.4. Risks HIGH context loss K=5, MEDIUM-HIGH K=10, multi-view identity and box-IoSA false visibility. Evaluate ORR/QEC/Answer-Witness Recall/SCR (proxy unless independent GT), Complete-Witness-Visibility@M, bridge retention, QA, latency/VRAM. Test K=10 M=1/2 ScanQA/SQA3D and M=1/2/4 MV-ScanQA with matched budgets within each M. V0 training-free, CPU selector; 8–16GB quantized 2B/4B VLM is only a feasibility target, not measured. Publication LOW standalone / MEDIUM integrated after significant matched-budget gains.

**Secondary diagnostic: Presence-versus-Visibility Evidence Gate (PVEG).** Distinguish missing-from-annotation vs omitted-by-selector vs not-visible-in-render. Training-free symbolic V0; optional PROVE-based variant requires training. Scores N1.9 Gain2.7 Feasibility3.4 Compute3.5 Fit4.4 Evidence4.2. Context-loss risk remains if annotations incomplete. Not promoted into ranked main shortlist.

**Priority:** keep SAFER-QA #1, OpenSlotSoft #2, Role-Aware Witness Coverage #3; treat VCWA as an evaluation-informed refinement rather than displacing existing tested candidates. Next CPU-only: inspect MV-ScanQA schema and annotate 50–100 independent support examples. ## 29 Oct addendum — direct published QGAP prior art and pose-dependence audit
Daily: [2026-10-29.md](../daily/2026-10-29.md). Official cs.CV/new listing observed **28 Oct** on 29 Oct scan; no confirmed separate 29 Oct listing. **No GPU benchmark.**

**IMPORTANT PRIOR ART: 3D-SceneQ**, Shan et al., **IEEE Transactions on Multimedia 28:5972–5983 (2026)**, DOI https://doi.org/10.1109/TMM.2026.3668502 , arXiv first submitted **27 Oct** https://arxiv.org/abs/2610.37202 ; HTML https://arxiv.org/html/2610.37202v1 . Peer-reviewed journal. Query-Guided Adaptive Pruning (QGAP) uses frozen BERT(question) vs BERT(predicted object labels) cosine ranking, learned latent query to predict gamma, retains k=round((gamma/2+0.5)n) => **nominally 50–100% of object tokens**. It prunes **after 3D object-token extraction**, not a pre-render K<<N physical subscene. MOFE fuses multi-view OpenSeg pixel embeddings into 3D tokens. Two-stage trained **Vicuna-7B**, **122.6M trainable parameters**, 2x A800 GPUs; not training-free, peak VRAM unknown, **no official code verified**. ScanQA val **CIDEr 104.7**, SQA3D test **EM@1 67.0%**; baseline **101.4/50.0**; QGAP-only **101.6/70.1** (higher SQA3D EM than full). These are trained 3D LLM results, **NOT** comparable with frozen <=7B 2D VLM without controlling data/backbone/training. QGAP is direct prior art for question-guided object pruning on exactly ScanQA/SQA3D; **generic adaptive pruning cannot be claimed novel**. Add **QGAP-inspired frozen BERT label Top-K** at matched K as a semantic baseline, explicitly NOT an official QGAP reproduction. No supporting-object GT or ORR/QEC/SCR reported.

**EgoAlign** arXiv 12 Oct https://arxiv.org/abs/2610.16176 , preprint, training LoRA/projections on point-cloud LLM, code promised not verified. Pose-shuffle finding on SQA3D: PoseAlign model with situation text 54.22->54.39 EM, EgoAlign 61.21->52.09; strong pose-insensitivity warning. **Does not prove our PoseAlign-T 2D rendering pipeline is insensitive**. Add cheap counterfactual pose/heading evaluation, with valid counterfactual answers; no new model training.

**Keizer et al.** *A Modular Approach to Conversational Object Grounding in 3D Scenes Using VLMs and Prompt Chaining*, **ACL GroundLM 2026 workshop** https://aclanthology.org/2026.groundlm-1.74/ : zero-shot modular ScanNet grounding, up to 13% improvement and 63% less image processing vs its baselines, not ScanQA. Code/VRAM unverified. Additional prior art for modular retrieval/scene graph/clarification.

**GeoUG** arXiv submitted 26 Oct, https://arxiv.org/abs/2610.36022 , preprint, trained depth/multiview generator + RL decision, no ScanQA, no verified code/VRAM; reinforces TASE evidence-format ablation only.
