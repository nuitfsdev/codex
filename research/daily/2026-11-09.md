## Research decision: evaluate set-valued witness coverage, not naive support recall
The highest-utility refinement is a **protocol correction**, not a new method: multiple different supporting-object sets can each suffice for the same QA. Annotate admissible minimal witness bundles W(q) = {W1,...,Wt} and measure CWC(q,S) = max_{W in W(q)} 1[W subset S]. If exhaustive W(q) unavailable, report only sampled-witness coverage / lower-bound evidence, not certified sufficiency. Named seeds (explicit question entities), unnamed answer candidates, and supporting context must be separate fields. Count/negation/existence require special completeness certificates, not just a selected witness set. Do not use answer or support GT in selector inference.

## Candidate: Set-Valued Witness Coverage Protocol (SVWCP), evaluation-only
- Hypothesis: set-valued witness annotations yield a more faithful evaluation of context loss than single support-object recall, and reveal whether semantic Top-K truly drops necessary unnamed answer/support evidence.
- Changed stage: independent ScanQA validation annotation and object-selection evaluation; not a detection/segmentation contribution.
- Object selection: compare frozen semantic Top-K, OpenSlotSoft and Role-Aware Witness Coverage on the same fixed object table, K=10; no oracle GT used to select.
- Supporting-context rule: retain explicit seeds and candidate answer/support relation endpoints; annotate multiple sufficient bundles independently and separate distractors. Only selected |S|<=K rendered by main method.
- Expected benefit: fewer false context-loss labels and credible go/no-go; **not an accuracy improvement claim**.
- Difficulty: medium/high annotation labor; training: none; compute: CPU annotation/geometry, no extra GPU VRAM for protocol; <=7B VLM GPU evaluation later, T4 peak VRAM unmeasured.
- Data: 50–100 stratified ScanQA validation questions (unnamed answers, same-class ambiguity, counting, negation, multi-hop), SQA3D later.
- Metrics: ORR=1-|S|/N, QEC for explicit named seeds, AWR for unnamed answer IDs, SCR for independently annotated supports (report per-bundle or proxy when incomplete), CWC, Context-Loss Rate, QA EM/CIDEr, latency, VLM calls and peak VRAM; stratify by question type and scene-clustered confidence intervals.
- Ablations: K=5/10/20, M=1 first, semantic Top-K vs OpenSlotSoft vs Role-Aware; single-vs-multiple valid witness annotations; support-vs-distractor removal; mesh-only/labels-only. Oracle only as evaluation ceiling.
- Risks: incomplete set of valid bundles, circular labeling, question ambiguity, camera visibility and counting/global negatives requiring scene-wide evidence certificates. Context-loss risk high K=5, unknown at K=10/20. ORR 50–85% and QEC >=95% unverified targets.
- Publication: low standalone, moderate value as evaluation backbone if downstream matched-budget gain is demonstrated.
- Scores /5: Novelty 1.2, Expected Accuracy Gain 1.0, Feasibility 4.1, Compute Cost 4.9 (higher cheaper), Fit 5.0, Evidence Strength 3.8. Subjective, no measured gains.
