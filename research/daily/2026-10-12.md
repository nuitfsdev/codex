## Candidate refinement: QASER-WitnessBudget (object+view joint evidence budget)
**Research hypothesis:** Under the same number of rendered objects, rendered views, and VLM calls, QA-role-aware pre-render retention of named seeds plus unnamed answer/reference witnesses will preserve answerability better than view-only active exploration or semantic Top-K; a cheap geometric visibility gate can prevent camera-alignment-induced loss.

**Stage:** QASER object-selection/QA-utility allocator + PoseAlign-T/view scheduler, before selective Abstract3D renderer. Not a replacement for core SAFER-QA.

**Object-selection rule:** Parse q into named seed(s), answer slot, attribute/relation, reference frame; retrieve candidates scene-wide from fixed GT object table (class synonyms/semantic score + box relation compatibility); retain ambiguous same-class alternatives where needed; never use exact noun match or seed-KNN as universal hard gates. Do not use ScanQA relevance/object IDs as selector input.

**Supporting-context rule:** Reserve objects that fill an unnamed answer endpoint, disambiguate a seed, witness a required relation, or anchor reference frame. Greedy maximize weighted coverage of required QA roles under K; explicitly log unmet roles. Small optional context reserve. No full-scene mesh/RGB render.

**View/stopping rule:** PoseAlign-T then test a small finite set of poses with box/mesh visibility proxy only for selected objects. Choose up to M views maximizing visibility of seed+answer/reference witness pairs and new relation evidence; stop once each required witness has sufficient observable evidence or budget exhausted. If visibility fails, change view before removing support; never add unselected objects by rendering full scene.

**Expected benefit:** Lower answer-witness loss and better QA-vs-render-cost frontier, especially spatial relations and occluded support. Not an observed accuracy gain.

**Implementation/compute:** medium; GT box scoring CPU, optional low-res mesh visibility check, no training in V0; selector extra VRAM ~negligible architecturally, VLM VRAM depends on 2B/4B quantization, image resolution, M and context; a local 16GB GPU is a plausible trial setup, NOT measured. Limit VLM calls to <=1 or <=2 for primary comparison. CoV's API multi-step workflow is a research reference, not an equal-cost baseline without normalizing calls.

**Datasets/metrics:** ScanQA val CIDEr, EM; SQA3D val/test EM with split labels; ORR=1-|O_sel|/|O_scene|; QEC for explicitly named entities; Supporting-Context Retention only with independently annotated support GT, otherwise clearly labeled proxy; relation-witness coverage, support co-visibility, missing-context rate, rendered objects/views, tokens, VLM calls, wall-clock latency, peak VRAM; stratify by question type. Target ORR 50-85%, QEC>=95% is a target only; SCR unmeasured; context-loss risk medium/high at K=5.

**Ablations:** same VLM/prompt/splits and K={5,10,20}, M={1,2,4}: Full Scene; SemanticTopK; Seed+KNN; relation-only QASER; QASER+RoleBudget; QASER+WitnessBudget; QASER+WitnessBudget+visibility gate; CoV-style discrete-view policy on SAME selected objects; and where feasible full CoV as a separate non-matched external reference. Compare at fixed (K,M,VLM calls) and separately QA-vs-total-cost. Counterfactual remove unnamed witnesses vs equal-number random objects; manual audit 50-100 validation relation questions, not test GT.

**Risks:** incomplete box visibility proxy, ambiguous referents, different answer wordings, role scorer weights/calibration, additional view latency, co-visibility may not be necessary if multi-view aggregation is effective. **Publication potential:** moderate only if matched-budget ScanQA/SQA3D improvement is stable and statistically supported; generic active-view search is already CoV prior art.

**Scores /5 (subjective research triage, not measured):** Novelty 3.1 integrated (1.8 standalone), Expected Accuracy Gain 3.6, Feasibility 4.6, Compute Cost 4.5 (higher=cheaper), Fit 5.0, Evidence Strength 4.8 (prior-art evidence strong; direct QA improvement untested).
