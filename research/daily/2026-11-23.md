# Daily Proposal Research — 2026-11-23 (W48)

## Finding: AgentGrounder is a strong previously missed prior (not a new November publication)
- Paper: https://arxiv.org/abs/2605.25901 (May 25 2026); code: https://github.com/be2rlab/AgentGrounder; repository README identifies ICRA 2026 MM-Spatial & SRRA workshops (workshop, not main ICRA). Code and ScanRefer/Nr3D preparation/inference instructions visible. Training-free online reasoning, but offline segmentation uses Mask3D and repository downloads Rex-Omni/SAM3. Model VRAM and precise full-stack compute not reported/verified.
- Pipeline: offline Object Lookup Table (id, semantic label, center, box size), online query decomposition, label candidate retrieval, deterministic geometry scoring, optional on-demand rendering only selected IDs, final object grounding. Reported ScanRefer +2.5 pp Acc@0.5 and Nr3D +6.3 pp vs SeeGround in abstract; manuscript body reports different Nr3D gain, so do not quote a definitive Nr3D delta until reconciled. Neither ScanQA nor SQA3D tested.
- IMPORTANT novelty collision: fixed-object-table candidate retrieval + geometric scoring + selective rendering already implemented for 3D grounding. Merely replacing segmentation with fixed GT annotations, selective rendering, tool calls, or named-seed retrieval is NOT a defensible novelty claim. Our remaining testable distinction: open-ended QA requiring unnamed answer and supporting witnesses, evidence completeness under strict K and matched image/VLM budgets.

## Candidate AG-QA-Witness (adaptation, NOT independent novelty)
- Hypothesis: role-aware unnamed witness expansion on top of AgentGrounder-style OLT retrieval improves QA accuracy-vs-K relative to label-based retrieval while maintaining strict pre-render object budget.
- Stage: question parse -> pre-render physical object selection; PoseRecover/PoseAlign-T/render unchanged.
- Rule: extract named seed instances with semantic aliases (not exact noun-only); keep ambiguous same-class anchors; scan ALL fixed boxes for unnamed answer candidates using relation compatibility (not hard distance filter); select at most K=10. Support rule: reserve candidates for relation endpoints, alternative anchors, intermediate objects and evidence completeness; for counting/negation use full metadata check, do not infer completeness from rendered subscene.
- Expected benefit: higher answer-witness recall and EM/CIDEr at equal K; unverified.
- Implementation: medium; metadata geometry CPU O(N^2) worst case; optional small embedding encoder CPU; no dedicated selector GPU; quantized 4B VLM on T4 16GB target, peak VRAM and latency unmeasured. AgentGrounder original full stack may exceed this due to pretrained perception models; bypass offline perception using fixed annotations.
- Data: ScanQA validation then SQA3D. Metrics: EM, CIDEr, ORR=1-|S|/N, QEC, independently annotated SCR, Answer-Witness Recall, Complete-Witness Coverage, loss-of-context, render time, VLM calls, peak VRAM. SCR unknown until 50-100 independent witness annotations.
- Ablation: same K=10, M=1 and VLM/prompt/renderer: semantic Top-K, AgentGrounder-style label+geometry retrieval adapted to QA, CAPruner adapted, SAFER-QA, SAFER-QA minus support expansion. Also K=5/20, witness removal vs distractor replacement. Keep original AgentGrounder grounding task results separate.
- Risks: wrong query roles; missing unnamed target; same-class ambiguity; reference frame for left/right; incomplete count/negation evidence; label shortcut; extra agent calls. Publication potential conditional/modest without demonstrable new algorithm and matched-budget gain.
- Scores 1-5 subjective (Compute 5=cheap): Novelty 1.3, Expected Gain 3.2, Feasibility 4.5, Compute 4.6, Fit 5.0, Evidence 4.4. Object reduction 50-85% target only; QEC>=95% target only; SCR unmeasured; context-loss risk high at K=5.
