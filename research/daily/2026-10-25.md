## 1. IMPORTANT VERSION UPDATE: SpatialMem v3 (22 Oct 2026; newly surfaced as replacement 23 Oct)
Primary paper: https://arxiv.org/abs/2601.14895 ; HTML https://arxiv.org/html/2601.14895v3 . Authors Xinyi Zheng et al. arXiv preprint, peer-reviewed venue NOT verified. Earlier v2 was 5 Mar; v3 has MATERIAL expanded benchmark evaluation (not a newly authored paper). Constructs hierarchical metric 3D memory with walls/doors/windows as structural anchors, object nodes, attributes and anchor-relative relations, linked evidence frames. Heavy monocular VGGT reconstruction is OUT OF SCOPE; transfer only lightweight anchor-path retrieval over existing annotated objects.
Evidence: 288 VSI-Bench videos / 5130 QA (one failed reconstruction), score 37.5; OpenEQA ScanNet subset 953 questions/79 scenes: same answerer and K=8 frames, memory retrieval 62.0 vs uniform 61.6, whereas text-serialized memory 35.1 vs blind 44.5 (LLM-Match judge, NOT ScanQA CIDEr). At K=2 retrieval 52.7 vs uniform 50.0; frame-budget gains are small. On 12 ScanNet scenes with official instance annotations, 573 relation and 471 retrieval probes, anchor hierarchy helps structural parent assignment, but RGB-only instance retrieval SR@0.5 0.18 versus privileged-input ConceptGraphs 0.41. Paper reports ~14.3KB query index per scene excluding linked images, NOT whole pipeline memory/VRAM; ~118s offline build. This cautions against text-only evidence replacement and establishes structural-anchor hierarchy as prior art. Authors say suites/memories/code available, but official public code URL could NOT be independently located; reproducibility UNVERIFIED. No ScanQA/SQA3D result. Source https://arxiv.org/html/2601.14895v3 .

## Candidate A: Anchor-Path Witness Budget (APWB), SAFER-QA refinement
Research Hypothesis: for QA requiring structural references, retaining a compact path of named seeds + unnamed answer candidates + existing annotated structural anchor(s) before rendering improves answer correctness at fixed K vs generic role-only witness allocation, without increasing distractors on questions that do not require anchors.
Stage: question-conditioned object selection (role parsing and budget allocation); optional spatial verification after PoseAlign-T.
Object-selection rule: parse q into {explicit seeds, open answer slot, relation, reference frame, structural-reference flag}; frozen BGE-small/MiniLM retrieves named seeds by label/synonyms, retaining ambiguous instances. Scan ALL fixed annotated objects with soft relation scores; do NOT exact-noun-match or KNN hard-gate unnamed answer candidates. For structural questions, generate short candidate anchor paths, e.g. window -> wall -> unnamed answer object, using existing annotations/boxes ONLY.
Supporting-context rule: retain required answer endpoint(s), relation witnesses, competing candidates, same-class disambiguators and, only when structurally relevant and annotated, wall/window/door/room boundary objects. If structural objects are NOT in fixed annotations, mark unsupported, do NOT invent detection or silently use test GT. If not structural question, spend no slots on anchors. Candidate bundle score U(W)=semantic_seed + soft_relation + role_completeness + anchor_path_consistency - redundancy, under |selected union|<=K. These are heuristics, not measured.
Expected benefit: fewer missing-reference/context errors in wall/window/corner and multi-hop relational questions, possibly better QA at small K; effect likely limited if such questions rare. Difficulty medium. Training-free CPU: cached embeddings, O(N^2) worst-case geometry; ~0 dedicated GPU VRAM for CPU selector. Complete pipeline 2B/4B quantized 8-16GB is only a feasibility TARGET, not verified. Data: ScanQA val/SQA3D val; question-type audit; K=5,10,20; M=1,2; matched VLM <=7B, same prompt, rendering and VLM-call budget. Metrics CIDEr/EM, SQA3D EM, ORR=1-|S|/N, QEC named-seed coverage, Answer-Witness Recall, Supporting-Context Retention (only true GT with independent labels; otherwise PROXY), Anchor-Path Coverage, context-loss, latency/VRAM. Paired support-removal and label+box-only controls; annotate 50-100 validation questions with support sets, not test GT used for selection. Ablate SemanticTopK, OpenSlotSoft, Role-Aware Witness Coverage, +anchor flag, +path allocation, +PoseAlign-T; report structural/nonstructural subsets separately. Risks: walls may be unannotated; structural hierarchy is known prior art; wrong anchor consumes K; HIGH context loss K=5, MEDIUM K=10; evidence from SpatialMem is different task. Publication: low standalone, medium ONLY as component if improves QA-object budget vs strong baselines.
Scores /5: Novelty 2.5; Expected Gain 3.1; Feasibility 4.4; Compute Cost 4.7 (higher=cheaper); Fit 4.7; Evidence 3.8. ORR 50-85% / QEC>=95% remain UNVERIFIED targets.

## Candidate B: Typed Evidence-Channel Gate (TECG), low-priority refinement
Hypothesis: selectively choosing selected-render evidence, box-based structured facts or short evidence descriptions based on question type improves QA reliability vs always attaching every channel. Stage: structured reasoning / answer input, AFTER the fixed K selector; object selection unchanged; unnamed supporting objects preserved as in SAFER-QA; no full scene render. Use count/metric/existence geometry as explicit symbolic-only channel and appearance/color as selected-render channel; relational questions combine selected render + frame-aware box predicates. Never label symbolic-only success as visual QA. Training-free CPU routing; no added GPU VRAM, extra calls only in ablation. Metrics per-type ScanQA/SQA3D, visual vs box-only answer delta, ORR/QEC/SCR inherited, latency/VRAM. Ablate render-only, box-only, render+box, gated channel, identical K/M and VLM; risk metadata shortcut, wrong question classifier, box-only may outperform because annotation oracle; publication LOW standalone. Scores N1.9 G3.0 F4.7 C4.8 Fit4.7 Evidence4.3. Motivated by ViewMind3D per-type regression and SpatialMem text-serialization failure, NOT direct 3D QA proof.
