## Candidate: Bounded Witness-Graph Sufficiency Check (BWGSC), SECONDARY
**Hypothesis:** deterministic pre-render completeness tests for seed–answer–support witness bundles can reduce unsupported QA and expose failure modes of strict K-selection.
**Stage:** question-role parser -> candidate selector -> evidence sufficiency gate (before PoseAlign-T/render), optional post-answer geometry verification.
**Object rule:** retrieve named seed IDs with frozen semantic encoder; generate unnamed answer candidates scene-wide from box-based soft relations, not exact noun/KNN gate; choose top witness bundles with union size <=K. All-scene object table used for inexpensive metadata *candidate scoring only*; images always render only selected K meshes.
**Support rule:** preserve relation endpoints, disambiguating same-class instances, intermediate relation anchors; explicitly flag counting/negative/existence questions for which selected subset cannot certify a scene-wide claim. If no complete witness bundle fits K, mark insufficient, do not pretend S=whole scene.
**Benefit:** better calibration/diagnosis of context loss; accuracy gain uncertain, may reduce coverage.
**Difficulty:** medium. **Training:** none. **Compute:** CPU O(N^2) candidate pair scoring; no extra selector GPU VRAM. 2D VLM <=7B peak VRAM remains model/image-dependent, unmeasured; T4 16GB target only.
**Metrics:** ScanQA CIDEr/EM, SQA3D EM; ORR=1-K_selected/N; QEC (named seed), AWR (unnamed answer), SCR only if independent supporting-object GT (otherwise PROXY); context-loss, selective accuracy/coverage, abstention rate, latency, VLM calls, VRAM.
**Ablations:** Semantic Top-K vs Role-Aware Witness Coverage vs +BWGSC, gate off/on, K=5/10/20 M=1, then M=2; matched renderer/prompt/VLM/calls; analyze counting/negation/same-class separately.
**Risk:** box relation uncertainty, incorrect parsing, abstention reducing answered coverage, metadata leakage. **Publication:** LOW standalone (RieMind/PEPS prior); possible supportive analysis only.
