## Candidate A: Relation-Contrastive Open-Slot Witness Reranking (RCOW) — selector refinement
Research hypothesis: At fixed K, testing *competing spatial relation hypotheses* for scene-wide unnamed answer candidates before rendering will reduce distractor retention while preserving complete seed–answer–support bundles compared with soft relation ranking alone.
Stage: pre-render question-conditioned object/subscene selector; optional PoseAlign-T frame verification.
Object-selection rule: parse q into explicit named seeds, open answer slot, relation, frame, attributes; frozen BGE-small/MiniLM ranks named seed instances with synonyms and preserves ambiguous alternatives. For EVERY fixed annotated object a, score its possible unnamed answer/support role using soft box geometry in the appropriate frame. No exact-noun or KNN universal gate. Example left-of vs right-of contrastive margin d(a)=r_left(a,seed|frame)-r_right(a,seed|frame); next-to vs far use calibrated soft distance, not a directional inverse. Retain multiple competing candidates when margins are small; no hard threshold until pose is resolved. This scoring is a PROPOSAL, not HSGG's original equation. Rank complete witness bundles rather than independent objects, under union budget |S|<=K.
Supporting-context rule: preserve explicit seeds, plausible unnamed answer endpoints, relation witnesses, same-class seed disambiguators, frame anchors, and competing alternatives. Never require an unnamed answer to semantically match a noun in the question. Do not spend slots on arbitrary neighbors. All scene objects may be scanned in metadata; only S is rendered.
Expected benefit: fewer relation-inconsistent distractors and fewer missing-answer errors on relational ScanQA/SQA3D. Unmeasured.
Difficulty: medium; no task-specific training for V0; cached text embeddings + CPU O(N^2) pairwise geometry worst case. Dedicated selector GPU VRAM ~0 if CPU. Full 2B/4B 4-bit VLM 8-16GB is a **feasibility target**, not a measured guarantee; <=7B model and image count need profiling.
Evaluation: ScanQA val CIDEr/EM, SQA3D val EM, ORR=1-|S|/N, Question Entity Coverage (named seeds), Answer-Witness Recall, Supporting-Context Retention (GT ONLY if independent manual support labels; otherwise proxy), Complete-Witness Coverage, Distractor Density, context-loss rate, latency, peak VRAM. At K={5,10,20}, M={1,2}; same backbone/prompt/renderer/calls. Ablations: BGE Top-K, OpenSlotSoft, Role-Aware Witness Coverage, RCOW with/without contrastive score, with/without PoseAlign-T, fixed frame vs pose hypotheses, with/without support reserve, box-only/label+box/render-only and paired support-removal. Independently annotate 50-100 validation QA witness sets before interpretation.
Risks: contrastive predicates are prior art; pose/frame ambiguity; "next to" not uniquely specified; noisy box geometry; multiple valid answers; risk HIGH K=5, MEDIUM-HIGH K=10; negative/count questions require separate completeness logic.
Publication: LOW standalone, MEDIUM integrated only with statistically robust downstream QA-vs-object-budget gain vs strong matched baselines. Scores /5: Novelty 2.5, Expected Accuracy Gain 3.3, Feasibility 4.5, Compute Cost 4.7 (higher=cheaper), Fit 4.9, Evidence Strength 3.6. No benchmark evidence yet.

## Candidate B: Gated Support-Evidence Restoration (GSER) — secondary post-render ablation
Hypothesis: when a selected-subscene answer is uncertain, swapping a low-value distractor for the next-ranked unnamed witness and selectively re-rendering at unchanged K can improve QA without full-scene rendering.
Stage: evidence verification / optional one-step view or object refresh after initial selected render.
Object-selection rule: initial S comes from SAFER-QA; seed and witness roles are explicit. A gated step uses answer disagreement/uncertainty to replace an expendable distractor with a scene-wide next-best support candidate; never increase K or render full scene.
Supporting-context rule: hard-retain named seed(s), required reference objects and best existing witness; never remove the only plausible answer endpoint. If no replaceable slot, abstain/mark insufficient instead of silently exceeding budget.
Expected benefit: recovery of missed witnesses on ambiguous queries, NOT proven on 3D QA. Difficulty medium-high; training-free heuristic V0; extra CPU ranking and one sequential VLM inference. Peak VRAM similar to base VLM if calls sequential, latency/token budget may nearly double in gated cases (estimate, NOT measured).
Metrics: downstream QA, ORR/QEC/SCR, Answer-Witness Recall, recovery rate, context-loss, gate activation, calls/question, latency, peak VRAM. Ablations: no gate vs uncertainty gate vs random replacement vs oracle support replacement (analysis-only); match TOTAL VLM calls or report compute/accuracy Pareto. Risk: VLM uncertainty poorly calibrated, replaced distractor may actually be necessary, confidence gains may reflect extra compute. Publication LOW standalone.
