## Direct-prior audit A — ViewMind3D (previously missed; IMPORTANT)
*ViewMind3D: Modular View-Aware Inference for Training-Free 3D-QA*, Ping-Kun Chiang et al., submitted **30 July 2026**, https://arxiv.org/abs/2607.28442 ; arXiv **preprint**, no independently verified peer-reviewed venue; **no official code repository located** in paper/search; ScanQA/SQA3D public benchmarks, but not newly released dataset.

Four modules: (1) query-adaptive relevance view selection from existing **full-scene RGB views**, (2) open-vocabulary guided detection/phrase bounding-box overlays, (3) BEV viewpoint indicators, (4) structured role-based multi-view QA. **Inference-only** (no model weight updates), but uses **GPT-4.1/o3 APIs**, NOT local <=7B. Paper Table I: ScanQA val CIDEr **73.41** with o3, **68.30** with GPT-4.1; Table II: SQA3D test average **50.75%** with o3. Paper reports ~**90K tokens and ~120s/query** for full pipeline, ~25K view selection + 30K guided detection + 35K QA; these are author measurements and NOT local VRAM. No T4 peak VRAM reported. Strong PRIOR ART for training-free modular 2D-VLM multi-view 3D-QA, question-driven view selection, BEV pose indicators, guided object cues and structured reasoning. **Cannot claim modular 2D VLM 3D QA, view-aware reasoning or role decomposition alone as novelty.** Unlike SAFER-QA, it starts with RGB views of the scene and applies visual grounding there; it does NOT specify strict pre-render physical-object selection from fixed 3D boxes, retaining unnamed QA witness bundles under K<<N. Not directly comparable under local backbone/compute constraints. Benchmark protocol/metric comparability needs checking before numeric comparison.

Code contains implementation, configs, evaluation, scripts, docs. Datasets ScanNet200 and real-world maps; **not ScanQA/SQA3D QA**. Original pipeline has Mask3D/OneFormer3D + SAM/CropFormer 2D/3D segmentation; OUT OF SCOPE for thesis. Reuse only routing logic on GIVEN boxes/labels. CLIP/SigLIP2 image-text descriptors + temperature-calibrated softmax confidence (max probability, top1/top2 margin, entropy) -> invoke Qwen2.5-VL-7B only for ambiguous cases. No full 3D-QA training, but temperature fitting on held-out tuning split and pretrained models; not wholly parameter-free. Authors report ScanNet200 oracle-mask SigLIP2 mAP **48.4 (no VLM), 51.9 (selective), 50.8 (always)**; CLIP **32.9/43.6/42.8**. These are **semantic segmentation/category mAP**, NOT ScanQA QA, and 39–62% of instances escalated in project examples; per-case ~50ms fast / ~2s escalated on original system, NOT measured T4. Full segmentation pipeline VRAM unknown; Qwen 7B may exceed T416GB depending precision/context. **Confidence-gated VLM escalation is PRIOR ART; cannot claim as new.** However its routing is primarily category/instance recognition, not preserving unnamed answer/support objects before selected-only rendering.

## New SECONDARY candidate — Question-Role Calibrated Witness Gate (QRCWG)
**Research Hypothesis:** Under strict K-object pre-render budget, allocate support slots only when the question has an open unnamed answer slot, ambiguous named seeds, or a multi-hop relation; preserve named seeds plus *scene-wide* unnamed answer/context witnesses more reliably than generic confidence gating or semantic Top-K, without extra VLM calls.
**Changed stage:** question-conditioned object/subscene selection BEFORE PoseAlign-T/rendering.
**Object selection:** frozen MiniLM/BGE/BERT embedding retrieval for explicitly mentioned seed instances; parse question role graph, type (attribute/identity/location/count/existence), ambiguity and answer-slot openness. Generate all-scene candidate endpoints from GT boxes/labels and soft relation compatibility. Gate g(q) from deterministic role/ambiguity rules (no learned confidence model in V0); under K allocate seed/answer/context reserve with g(q), rank complete witness bundles rather than isolated nouns. No hard exact noun match or nearest-neighbor cut; preserve multiple same-class hypotheses if ambiguous. Render ONLY selected S, |S|<=K, never whole scene.
**Supporting context rule:** retain unnamed answer candidates, relation bridges, seed disambiguators, frame anchors and competing candidates when they complete evidence; distinguish missing-from-annotation, unselected and invisible. For counting/existence/negative questions mark incomplete evidence / abstain instead of treating selected subscene as whole scene. Context reserve test 0/10/20/30% of K; gate must not suppress unnamed answers just because seed confidence is high.
**Expected benefit:** improved Answer-Witness Recall and QA-vs-ORR at K=5/10 without extra VLM calls; hypothesis unverified.
**Implementation difficulty:** low-medium CPU; no training V0; optional tiny calibrated logistic gate only with training split and scene-separated validation.
**Compute/VRAM:** cached embeddings and box geometry O(N^2) worst case, CPU; ~0 additional GPU VRAM for selector, overall 2B-4B 4-bit VLM T4 16GB is a planning target, not verified; no daily GPU run.
**Data/metrics:** ScanQA/SQA3D val, independent 50–100 question support IDs for GT SCR; ORR=1-|S|/N; QEC named-seed coverage; AWR unnamed-answer recall; SCR supporting-context retention ONLY if independently labeled (else proxy); Complete-Witness Coverage, Context-Loss Rate, same-class seed binding, QA EM/CIDEr, latency/peak VRAM, scene-clustered confidence intervals.
**Ablations:** at K=10 M=1 fixed same VLM/render/prompt/calls compare MiniLM/BGE/BERT semantic Top-K, OpenSlotSoft, Role-Aware Witness Coverage, QRCWG (gate off/on), constant vs adaptive reserve, K=5/20, then M=2. Also box-only/label-only/render-only and support-object removal. No GT relevance labels in selector.
**Risks:** question role parser fails; false confidence suppresses needed context; K=5 high context loss, K=10 medium-high in multi-hop; counting/existence not answerable from incomplete render; symbolic shortcut risk.
**Publication potential:** LOW standalone (Scene-Q confidence routing, ViewMind3D role decomposition and earlier QASER context reserve prior art), MEDIUM as integrated SAFER-QA ONLY if measured QA-witness improvement under matched budgets. **Scores /5:** Novelty 2.0, Expected Gain 3.3, Feasibility 4.7, Compute 4.8 (higher=cheaper), Fit 5.0, Evidence 4.2 (PRIOR strength, not candidate validation). **Targets** ORR 50–85%, QEC>=95% UNVERIFIED; SCR independent GT missing.

## New SECONDARY ablation — Identity-Aware View-Overlap Budget (IAVOB)
**Hypothesis:** with stable 3D instance IDs, remove redundant selected-object observations across M views without dropping relation-witness visibility, improving inference efficiency without degrading QA. **Stage:** view selection/multi-view aggregation after selecting K physical objects. **Rule:** S unchanged from SAFER-QA; choose M views to cover witness object IDs and required relation edges while penalizing duplicate visibility. **Supporting rule:** no view pruned if it uniquely shows an unnamed answer/bridge/anchor; maintain ID correspondence. **Training:** none; CPU box-projection estimates + optional low-res selected-only mesh visibility. **Difficulty:** medium. **Compute:** O(MK^2) approximate, VLM cost varies with view count; VRAM not measured. **Metrics:** QA EM/CIDEr, ORR/QEC/AWR/SCR inherited, witness visibility@M, view overlap, visual tokens, latency/VRAM, context loss. **Ablation:** random M views vs pose-only vs object coverage vs relation-edge coverage; M=1/2 under matched image token budget. **Risks:** box visibility != mesh occlusion, reduced views can lose complementary evidence; context loss medium/high. **Publication:** LOW standalone because geometry-aware token/view redundancy prior art. **Scores:** N1.6 Gain2.9 F4.3 C4.4 Fit4.8 E4.2.
