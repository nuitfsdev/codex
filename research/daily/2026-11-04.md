## Candidate A — Context-Removal Counterfactual Audit (CRCA), evaluation-only
**Hypothesis:** selective instance-mesh rendering changes VLM answers partly through context removal rather than only improved object relevance. **Stage:** renderer/evaluation/spatial verification. **Selection:** freeze SAFER-QA selected S, |S|<=K; never render full scene for main inference. **Support:** retain fixed named seed, unnamed answer and relation witness IDs; compare selected renders with controlled deletion of a supporting object versus equally sized irrelevant-object deletion; account for occlusion and image composition. **Expected benefit:** causal diagnostic, NOT presumed accuracy gain. **Difficulty:** medium. **Training:** none. **Compute:** CPU manipulation + sequential VLM calls on existing <=7B backbone, no new model VRAM, total latency scales with conditions; peak VRAM unmeasured. **Data:** 50–100 independently annotated ScanQA/SQA3D validation questions; EM/CIDEr, paired answer change, ORR, QEC, AWR, independent-GT SCR (otherwise proxy), context-loss, calls/latency/VRAM. **Ablation:** selected render vs delete-support vs delete-distractor; label-only/box-only/mesh-only. **Risks:** deletion changes visibility/composition; GT support annotations missing; context loss high K=5. **Publication:** low standalone, valuable analysis for main paper. ## Candidate B — Group-Consistent Witness Expansion (GCWE), secondary
**Hypothesis:** selecting a minimal *complete* seed–answer–relation bundle rather than independent object Top-K reduces missing unnamed context at same K. **Stage:** question-conditioned object selection. **Rule:** frozen semantic named-seed retrieval, scene-wide soft relation candidate generation from fixed boxes, group edges from typed relation compatibility; greedy bundle gain per budget slot; no exact noun/KNN hard gate. **Support:** preserve unnamed answer, relation bridge and competing same-class anchors; keep |S|<=K and render ONLY S. **Expected benefit:** improve witness completeness, hypothesis unvalidated. **Difficulty:** medium. **Training:** none V0; optional lightweight reranker later only after baselines. **Compute:** CPU O(N²) pair relations; ~0 additional GPU VRAM; VLM peak unmeasured. **Data/metrics:** ScanQA/SQA3D QA EM/CIDEr; ORR/QEC/AWR/SCR with independent GT or proxy flag, complete-bundle coverage, context loss, latency/VRAM. **Ablation:** semantic Top-K, RWC, independent score vs bundle selection, K=5/10/20 M=1; same renderer/VLM/prompt/calls. **Risks:** relation scores from boxes weak, competing groups crowd K; counting/negation incomplete; HIGH context loss at K=5. **Publication:** low standalone (group expansion prior art), medium only if strict matched-budget QA gains.
