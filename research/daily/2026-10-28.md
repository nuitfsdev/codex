## Newly verified papers (do not confuse grounding, navigation, and QA metrics)
1. **RelateGS: Reliable Semantic and Relational Evidence for 3D Scene Understanding with Gaussian Splatting**, Seongjun Choi, Sangyoun Lee, submitted **24 Oct 2026**, listed 27 Oct; arXiv https://arxiv.org/abs/2610.33868 ; paper HTML https://arxiv.org/html/2610.33868v1 ; official repo https://github.com/DrawingProcess/RelateGS . **WACV 2027 accepted** per paper and repo; proceedings not independently checked. Method: confidence-filter weak multi-view Gaussian semantic observations, build persistent object graph, identify **under-observed relational edges**, re-query informative *existing* frames. Sr3D+ overall Acc@0.25 **15.3** vs GaussianGraph **7.4** (+7.9pp); Nr3D **10.3** vs **8.6** (+1.7pp). On Sr3D+ ablation at matched re-query count, random re-query A@0.25 **11.62**, graph-guided **15.28** (initial graph 12.12). These are **grounding, not ScanQA**. Paper reports **one A5000 24GB** for original 3DGS pipeline; does NOT establish peak VRAM. Repo currently README/docs only; inference/checkpoints/training/data are unchecked future release items. Not reproducible yet; no public runnable implementation verified. Full 3DGS reconstruction/semantic mapping and 2D SGG are out of scope. **Transferable principle**: distinguish relation *plausibility* from relation *evidence observability*, and prefer targeted evidence for uncertain QA witness edges. Relation-guided re-query itself is prior art.
2. **GeoLift: Grounding Video Spatial Reasoning in Explicit 3D Maps**, Xinglin Li et al., submitted **24 Oct**, listed 27 Oct, **arXiv preprint**, https://arxiv.org/abs/2610.33558 . All weights frozen, Qwen3-VL-4B; uses 2D grounding + feed-forward 3D reconstruction + superpoint cross-view association + symbolic spatial computation. VSI-Bench overall **55.4 -> 64.1%**, route planning **30.9 -> 53.6%**, MindCube **59.8%** (paper-reported, NOT ScanQA). No official code release or end-to-end VRAM verified. Full perception/reconstruction outside thesis scope; fixed object IDs already solve cross-view identity. **Transfer**: geometry-based cross-view relation verifier on selected object IDs and fixed poses; use as verification ablation, not novelty.
3. **Humans in Space / SATE-Bench**, Tianchen Guo et al., submitted **25 Oct**, listed 27 Oct; arXiv https://arxiv.org/abs/2610.34149 ; WACV 2027 per authors/repo (proceedings not independently checked); code https://github.com/gtc-gh/SATE-Bench ; data https://huggingface.co/datasets/gtc-hf/SATE-Bench . **316 scenes / 2,525 multi-turn QA**, active occluded-view exploration vs passive evidence-complete views; original task human-centric and NOT ScanQA. Public eval code/data; optional GRPO training, but inference-only evaluation possible. Qwen2.5-VL-3B: passive **50.9%**, active **30.4%**; GRPO increasing view-seeking may **reduce** active QA accuracy. Compute for local 3B inference must be profiled; full GRPO not recommended. **Transfer**: compare evidence completeness vs answer accuracy and a fixed M budget; avoid confidence-only early stopping or unlimited views.
4. **Representing the Unseen / ImagiRep + GEARS**, Zengqi Zhao et al., submitted **27 Oct**, cs.AI cross-list visible 28 Oct; arXiv https://arxiv.org/abs/2610.37437 ; project https://imagirep.github.io/ ; official code https://github.com/Imagirep/ImagiRep ; gated data https://huggingface.co/datasets/Imagirep/ImagiRep . **arXiv preprint**, not peer-reviewed yet. 922 questions (622 viewpoint imagination + 300 cross-view) on Matterport3D, seven representation options (RGB, depth, surface normals, panorama, top-down, spatial text, video). GEARS selects whether and what evidence to show; paper-reported **61.4%** viewpoint / **77.7%** cross-view on its benchmark with **GPT-6.1-sol**; NOT <=7B and NOT ScanQA. Code includes scripts and per-question outputs, but Matterport3D-gated data; original world-model generation and commercial reasoner are expensive; no validated single-T4 VRAM. **Transfer**: cheap *selected-object-only* question-type renderer routing as an ablation. Question-conditioned representation choice is PRIOR ART, not novelty.

## Candidate A — Relation-Observability Witness Budget (ROWB), object-selection track
**Research Hypothesis:** QA-specific pre-render selection that jointly preserves named seeds, unnamed answer/bridge/support endpoints and the *observability of required relations* can improve relational QA at matched K,M vs semantic Top-K and Role-Aware Witness Coverage.
**Changed stages:** relation-aware witness allocation before selected-mesh rendering; optional PoseAlign-T-conditioned view ranking. NOT perception/detection.
**Object-selection rule:** parse explicit seed mentions and open answer slots separately; frozen MiniLM/BGE-small + synonyms for seeds; scene-wide metadata search over ALL fixed annotated objects for unnamed candidates (no exact-noun or KNN hard gate). Build plausible relation-witness bundles W_h and their required edges E_h. Use soft box geometry to rank hypotheses and estimated pairwise visibility from camera frustum/3D boxes, without rendering full scene. Select union S, |S|<=K; views V, |V|<=M. A weakly observed but semantically essential edge triggers alternative view ranking, **not** silent dropping of the supporting object.
**Supporting-context rule:** retain seed disambiguators, unnamed answer endpoints, relation bridges, competing hypotheses and frame anchors when needed; do not automatically include all structural anchors. If evidence is impossible under K,M, record insufficient and abstention/proxy status. Keep alternatives when reference frame uncertain. For counting >K, do not claim visual completeness.
**Proposed objective (NOT from RelateGS):** max over S,V of sum_h u_h * 1[W_h subset S] * min_{e=(i,j) in E_h} obs(e,V) - lambda redundancy(S,V), with obs initially a projected-pair visibility proxy and optional selected-mesh occlusion check. Do NOT use full-scene rendering to compute obs.
**Expected benefit:** reduce selected-but-unobservable relation witnesses and context-loss errors; UNMEASURED. **Difficulty:** medium-high; V0 training-free. CPU O(N^2+N*|V_candidates|) rough planning bound, cached embeddings; selector ~0 extra GPU VRAM if CPU. Selected-mesh low-res visibility optional; VLM 2B/4B 4-bit 8–16GB is an UNVERIFIED planning range, not measured peak.
**Data/metrics:** ScanQA validation CIDEr/EM, SQA3D validation EM, relational subset, optionally MV-ScanQA after schema check. ORR=1-|S|/N; QEC=retained named seed IDs / required named seed IDs (only where ID labels exist); Answer-Witness Recall; SCR only with independently labeled supporting objects (otherwise explicitly PROXY); Complete-Witness Coverage; **Required-Relation Observability@M**; Context-Loss Rate; QA vs K/M; time and peak VRAM. K={5,10,20}, M={1,2}. Baselines semantic Top-K, OpenSlotSoft, Role-Aware Witness Coverage, RCOW, fixed PoseAlign-T vs joint view. Ablate edge-observability term, uncertainty/alternative views, box proxy vs selected-mesh occlusion, support reserve. Matched K,M, prompt, renderer, backbone, calls; paired scene bootstrap; box-only/render-only/support-removal controls.
**Risks:** box projection overstates visibility; partial-scene rendering removes occluders; relation ambiguity and pose errors; K=5 HIGH and K=10 MEDIUM-HIGH context-loss risk; extra view scoring may not help QA. **Publication:** LOW standalone (RelateGS/VCWA prior art), MEDIUM as integrated QA-budget contribution ONLY after significant matched-budget gains. **Scores /5:** Novelty 2.4; Expected Gain 3.3; Feasibility 4.2; Compute (higher=cheaper) 4.3; Fit 4.9; Evidence 4.0. Scores subjective, not benchmark.

## Candidate B — Type-Adaptive Selected-Object Evidence (TASE), secondary renderer/view ablation
**Hypothesis:** with the SAME selected K objects and same M/image-token budget, question-type-specific evidence format (instance mesh, selected-object BEV/box geometry, optional depth) improves spatial QA vs a fixed mesh-only representation.
**Changed stage:** Abstract Renderer / evidence-channel routing AFTER object selection. **Object rule:** unchanged SAFER-QA named-seed+unnamed-support S; no full-scene BEV, no extra unselected objects. **Supporting rule:** all channels preserve selected witness IDs; if metadata-only geometry answers counting/distance, report separately as symbolic shortcut, not visual VLM gain.
**Expected benefit:** relation/distance questions may prefer top-down, attribute questions mesh appearance; UNMEASURED. **Training:** none V0. **Difficulty:** low-medium. CPU simple routing; selected-only depth/BEV rasterization low-res; no additional VLM parameters, but extra render formats can increase tokens/latency. Single-view 2B/4B quantized 8–16GB is a planning target, not validated.
**Metrics:** ScanQA/SQA3D by question type; same ORR/QEC/SCR inherited from S; CIDEr/EM, frame consistency, tokens, latency, peak VRAM. **Ablations:** mesh-only, BEV-only, depth-only, concatenation, type-routing; fixed K=10 M=1; keep equal image-token budget; label+box-only controls. **Risks:** appearance cues lost in BEV, box/label leakage, wrong routing, redundant visual channels; context-loss inherited from selector (HIGH K=5). **Publication:** LOW standalone (ImagiRep/GEARS prior art), supportive integrated ablation. **Scores:** N1.8 Gain3.0 Feasibility4.6 Compute4.6 Fit4.7 Evidence4.3.
