## Paper 1 — Token-Budgeted Candidate Retrieval: strongest direct prior-art audit
**Michał Zakrzewski, Mariia Shpir, Taras Rumezhak**, *Token-Budgeted Candidate Retrieval for 3D Scene-Grounded VLMs: Category Names vs. Pairwise Geometry*, arXiv:2610.14207, submitted **9 Oct 2026**, https://arxiv.org/abs/2610.14207 . **Status:** authors list accepted NeurIPS 2026 Workshop on Physical World AI (**non-archival**, not NeurIPS main). **Code:** paper promises retrieval protocol, implementations and per-query logs; no official runnable repository verified. **Data:** ScanRefer gt_val (9508), Nr3D and Sr3D on custom 20%-scan-id split (NOT official ReferIt3D val), 35,504 queries across datasets. **Training:** retrieval training-free; MiniLM-L6-v2 (~22M) and BGE-small-en-v1.5 (~33M) frozen; pairwise QCRR analytic CPU geometry; downstream released 3DGraphLLM checkpoint, not frozen <=7B 2D-VLM. **Compute:** CPU semantic cache feasible, QCRR pairwise O(N^2); paper does not establish peak VRAM for full 3DGraphLLM harness.

ScanRefer gt_val target Recall@10: QCRR geometry **0.626**, additive noun **0.864**, MiniLM **0.911**, BGE-small **0.913**. On matched object budget, 3DGraphLLM **Acc@0.25**, n=300 ScanRefer queries: Random **0.443**, QCRR **0.557**, MiniLM **0.673**, full graph **0.670**, GT-incident oracle **0.697**. These are **grounding** metrics, NOT ScanQA QA gains. Geometry helps over naive kNN or some lexical paraphrases but does NOT beat frozen semantic retrieval. Their harness was corrected after relation-channel/ID/feature-key bugs; replicate ID mapping checks.

**Critical novelty constraint:** fixed-box query-conditioned retrieval, MiniLM/BGE category matching, pairwise geometric ranking, matched object budget and graph token-ratio evaluation are prior art. The untested SAFER hypothesis is **unnamed answer/support witness completeness for open-ended QA before physical-object rendering**; generic semantic-first+geometry alone is not publishable. Use MiniLM/BGE semantic Top-K as a strong mandatory baseline, not a weak strawman. Note their retrieval task typically names the *target category*, unlike open answer slots in ScanQA.

## Paper 2 — ClusterSplat (newly surfaced 28 Oct)
**Jaesung Lee, Hyeontaek Hwang, Gabriel Manalu, Daeyoung Kim**, *ClusterSplat: Semantic Cluster Selection for 3D Visual Grounding in Gaussian Splatting*, submitted **27 Oct 2026**, https://arxiv.org/abs/2610.36462 ; project https://jaesung8.github.io/clustersplat/ . **Status:** authors/project label **NeurIPS 2026 Spotlight**; independent proceedings not checked. **Code:** official project explicitly says **Code Coming soon**. **Data:** ScanRefer/ScanNet v2 common **10 scenes**, Ref-LERF; not ScanQA/SQA3D. **Training:** YES, instance-aware Gaussian features and query-conditioned two-layer MLP; frozen CLIP text encoder alone does NOT make pipeline training-free. Uses annotated training-frame instance masks and GPT-4.1 pseudo captions; project is not annotation-free. **Compute:** paper states single RTX 5090 for experiments, A6000 for efficiency timing; peak VRAM and complete training hours not established.

Approach: learn Gaussian instance features -> feature-aware seed voxels -> MDL-guided merging -> query-conditioned **Top-1** cluster scorer -> 3D target and rendered 2D mask. Project reports ScanRefer **2D mIoU 39.72**, **3D mIoU 23.33** (vs Dr.Splat 19.01/9.48 on their 10-scene comparison). NOT ScanQA QA. **Transfer:** candidate granularity and score-scale robustness are useful conceptual cautions, but we already have fixed annotated object instances, so DO NOT recreate 3DGS/segmentation/clustering or claim discrete candidate selection is new. ClusterSplat targets one referred object, not multiple unnamed QA witnesses.

## Paper 3 — P3-VLM (missed high-value 20 Oct prior)
**Anna-Maria Halacheva et al.**, *P3-VLM: A Point-based Alternative for Grounded 3D Vision-Language Models*, submitted **20 Oct 2026**, https://arxiv.org/abs/2610.28018 . **Status:** authors mark **NeurIPS 2026 Spotlight**; independent proceedings not checked. **Code:** no verified official implementation. **Data:** Nr3D/ScanRefer/ScanQA/SQA3D, ScanNet++ OOD. **Training:** YES; Qwen3-VL-4B LoRA r=16 + trainable SceneSplat 3D encoder and pathways, **10h on 2x NVIDIA H200**; not thesis-feasible reproduction, no measured peak VRAM.

**Important finding:** blind box-coordinate LLM class accuracy on Nr3D falls **36.4% -> 18.0%** when replacing box prompts with point prompts; geometry can leak object category without visual evidence. P3-VLM point variant reports ScanQA **EM-R 31.9** and SQA3D **EM-R 51.8** (trained 3DGS LMM, not comparable to frozen 2D-VLM). **Transfer:** add label-only, box-only, selected-render-only, box+label and label-shuffle controls; keep fixed boxes for selector inputs, but test whether QA success depends on rendered appearance. The paper does NOT imply that using fixed boxes as selector input is forbidden.

## Object-selection track — named seeds vs unnamed support
- Named seed IDs: identify explicit nouns/attributes in question; resolve instance ambiguity with frozen semantic category retrieval + role-compatible spatial constraints. No exact noun-only gate.
- Unnamed answer candidates: for “What is next to the refrigerator?”, retrieve refrigerator as seed, then evaluate **ALL fixed annotated objects** for possible answer role via soft near/far and semantic/role compatibility, even if their category is absent from the question.
- Unnamed support: keep relation bridges, same-class seed disambiguators, competing answer candidates and reference-frame anchors only when required. Preserve **complete seed–answer–support bundles** under union |S|<=K, not merely high individual relevance. Only S is passed to renderer; full annotation table is allowed for CPU selection.
- New caution from Token-Budgeted study: strong target Recall@K does not establish QA-support completeness; geometry-only scoring can be worse than frozen semantic retrieval. Conditional relation scoring must be tested as a **residual**, not assumed superior.

## Candidate A — Ambiguity-Gated Semantic-to-Witness Residual (AG-SWR), RWC refinement ONLY
**Research hypothesis:** At fixed K, use semantic-first ranking for named seed retrieval, but spend remaining slots on unnamed answer/support witness bundles *only* for questions with an open answer slot or ambiguous seed instances; this may preserve semantic precision while recovering evidence missed by independent Top-K. This is a specific implementation/ablation of Role-Aware Witness Coverage, **not** a new main novelty claim.
**Changed stage:** pre-render question-conditioned object selection.
**Object rule:** (1) parse question into named seed roles, open answer slots and relation cues; (2) rank all annotated objects by frozen MiniLM/BGE semantic relevance; (3) lock high-confidence named seeds, keep alternatives if same-class ambiguity; (4) for open slots or ambiguity, score relation-compatible candidate objects scene-wide using PoseAlign-T frame where needed; (5) allocate remaining K slots to highest-utility complete witness bundles; no full-scene render. In no-open-slot/no-ambiguity cases fall back to semantic Top-K.
**Supporting-context rule:** reserve 1–3 slots (or 10/20/30% of K in ablation) for bridge, competing answer, disambiguator, reference-frame anchor; do not assume nearest-neighbor or exact noun match. If support needs exceed K, mark evidence insufficient; never silently call it complete.
**Expected benefit:** potentially better unnamed Answer-Witness Recall and QA vs semantic Top-K without sacrificing QEC; **not measured**.
**Difficulty:** medium; training-free V0; CPU embeddings cached, O(N^2) worst-case relation scoring; selector ~0 dedicated GPU VRAM. 2B/4B 4-bit VLM on 8–16GB is planning target, not verified. **Data:** ScanQA/SQA3D val; optionally MV-ScanQA as stress test after schema audit.
**Metrics:** ScanQA CIDEr/EM, SQA3D EM, ORR=1-|S|/N, QEC, Answer-Witness Recall, SCR (GT only with independently annotated support; otherwise proxy), complete-bundle recall, context-loss rate, latency/peak VRAM. QEC also needs disambiguated seed-ID labels or is proxy.
**Ablations:** semantic MiniLM Top-K vs BGE Top-K vs QGAP-inspired frozen BERT Top-K vs geometry-only QCRR-inspired vs RWC vs AG-SWR; K=5/10/20, M=1/2; gate on/off, relation on/off, support reserve 0/10/20/30%; matched image-token and VLM-call budget; stratify open-slot, same-class ambiguity, counting, viewpoint-dependent; scene-bootstrap CIs.
**Risks:** semantic gate may miss implicit answer slots, geometry errors in camera frame, support-slot competition at K=5 (HIGH loss), K=10 MEDIUM-HIGH, counting often needs all candidate objects. **Publication:** LOW standalone (semantic-first and relation retrieval prior art), MEDIUM only if integrated SAFER shows reproducible downstream QA-vs-budget improvement.
**Scores /5 (subjective):** Novelty **2.2**, Expected Gain **3.4**, Feasibility **4.7**, Compute (higher cheaper) **4.8**, Fit **5.0**, Evidence **4.1**. No measured ORR/QEC/SCR; targets ORR 50–85%, QEC>=95% remain unverified.

## Candidate B — Visual Evidence Necessity & Shortcut Audit (VENSA), evaluation only
**Hypothesis:** Some gains from fixed-box/label prompts and selected renders may arise from metadata shortcuts, not true visual evidence; paired evidence interventions can quantify this.
**Changed stage:** evaluation and spatial verification, not core selector.
**Object rule:** freeze S from same selector (named seeds and unnamed candidates unchanged); render ONLY S, never full scene in main setting. **Supporting rule:** retain same supporting IDs across paired variants; perform one-at-a-time support removal and replace with matched distractor at fixed K only for *diagnostic* paired tests.
**Expected benefit:** credible novelty/causal evidence audit, NOT expected accuracy gain.
**Difficulty:** low-medium; no training. CPU metadata manipulations; extra sequential VLM calls for small sampled set, peak VRAM roughly baseline if sequential (unmeasured), inference time multiplies with ablation variants.
**Data/metrics:** 50–100 manually labeled ScanQA/SQA3D validation examples with independent support GT; paired EM/CIDEr delta, visual-dependence rate, support-ablation sensitivity, label/box leakage, ORR/QEC/AWR/SCR/context loss, latency and peak VRAM.
**Ablations:** selected render+labels vs render without class labels vs box-only vs label-only vs shuffled class labels vs support removal/replacement, fixed K/M; do not treat arbitrary perturbation-induced failure as causal proof, and check answer stability/visibility.
**Risks:** label shuffling can change task semantics, answer GT incomplete, context removal can alter occlusion, multiple valid supports; high risk of false causal interpretation. **Publication:** LOW standalone, HIGH value as validation of integrated claim.
**Scores /5:** Novelty **1.6**, Expected QA Gain **1.0**, Feasibility **4.4**, Compute **4.1**, Fit **4.9**, Evidence **4.7**.
