## Candidate A — Query-Paraphrase Stable Witness Selection (QPSWS), secondary object-selection
**Hypothesis:** under same K, agreement among equivalent relation-preserving question paraphrases can improve unnamed answer/support witness recall vs one-shot semantic Top-K without extra render/VLM calls.
**Stage:** question parsing and pre-render object selection.
**Object-selection rule:** extract named seed roles, retrieve seed instances by frozen semantic similarity (no exact-noun-only hard gate); produce 2–3 deterministic relation-preserving paraphrases (no generative VLM required), retrieve scene-wide unnamed answer candidates via soft box-relation scores, aggregate candidate ranks across paraphrases, allocate K to top complete seed–answer bundles. Preserve original question's coordinate frame, polarity and cardinality.
**Supporting-context rule:** retain named seeds, unnamed answer endpoints, relation bridges, reference-frame anchors and competing same-class disambiguators; reserve support slots; never render all objects; |S|<=K.
**Expected benefit:** robustness to question phrasing and higher AWR/SCR; NOT validated. **Difficulty:** medium. **Training:** none V0. **Compute:** CPU semantic encoder embeddings cached; ~2–3x selector CPU work, O(PN²) worst case; no extra selector GPU VRAM, full VLM peak unmeasured. **Data/metrics:** ScanQA/SQA3D QA EM/CIDEr, ORR=1-|S|/N, QEC, AWR, SCR only if independent supporting GT (otherwise proxy), complete-witness coverage, context-loss rate, latency/VRAM. **Ablations:** single query vs paraphrase consensus vs random paraphrase, with/without support reserve, same K=10 M=1 renderer and <=7B VLM/calls; K=5/20 later. **Risks:** paraphrases alter left/right frame or negation; consensus can suppress rare but correct candidates; K=5 context loss HIGH. **Publication:** low alone, medium only if matched-budget ScanQA gain + robust cross-paraphrase evidence. **Scores (1–5):** Novelty 1.9, Expected Gain 3.1, Feasibility 4.4, Compute 4.5, Fit 4.9, Evidence 3.7.

## Candidate B — Relation-Grounded Answer Check (RGAC), secondary verification
**Hypothesis:** independent deterministic box-relation consistency checks on selected witness IDs may detect label-prior spatial answers without more object rendering.
**Stage:** spatial verification after selected-only rendering and <=7B VLM. **Selection/support:** inherit SAFER-QA S and preserve seeds, unnamed answer and relation anchors; do not fetch full scene visual evidence. **Benefit:** reduced unsupported relational answers, not assumed accuracy gain. **Difficulty:** low–medium. **Training:** none. **Compute:** CPU O(K²) box relations, no additional model VRAM; optional second VLM call only as separately metered ablation. **Data/metrics:** ScanQA/SQA3D relational strata, EM/CIDEr, contradiction detection precision/recall, ORR/QEC/AWR/SCR inherited, context loss, latency/VRAM. **Ablations:** no verifier, geometry-only, pose-aware, label-only/mesh-only; correct vs perturbed pose. **Risks:** viewpoint/reference-frame ambiguity, annotation box approximations, legitimate answers outside selected S. **Publication:** low standalone. **Scores:** N1.5 Gain2.7 Feas4.7 Compute4.8 Fit4.7 Evidence3.9.
