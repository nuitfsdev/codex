# Daily Proposal Research — 2026-09-22

## Material update: PruneGround venue/status strengthened

PruneGround (arXiv:2606.31148) v2, submitted 2026-09-04, now identifies the work as **EMNLP 2026**; the authors' Jinesis Lab announcement lists it among EMNLP 2026 main-conference papers. Public code is available at `leduckhai/PruneGround` under MIT license. This upgrades PruneGround from a preprint-only novelty limiter to a peer-reviewed first-tier baseline for question/language-conditioned spatial pruning.

### Why this matters for the thesis
PruneGround's public pipeline already implements:
- frozen Qwen2.5-VL-3B language-guided spatial pruning (LGSP),
- multi-view description reformulation (MCDR),
- explicit `anchors_visual` for anchors absent from the original language,
- local rendering after pruning,
- public ScanNet-based implementation.

Therefore the thesis should NOT claim generic language-conditioned pruning, target-anchor decomposition, discovering unnamed visual anchors, or prune-then-render as the novelty.

## Candidate update: QASER-Utility

**Research hypothesis.** Objects useful for open-ended QA are not necessarily the same objects useful for referential grounding. Under the same object/render budget, a QA-utility selector that retains named seed objects plus unnamed answer-support/context objects can preserve downstream ScanQA/SQA3D accuracy better than grounding-oriented pruning such as PruneGround.

**Changed stage.** question-conditioned object/subscene selection before PoseAlign-T / Abstract3D rendering.

**Object-selection rule.** Hard-retain resolved seed/referred entities; generate scene-wide support candidates from relation constraints and cheap 3D-box geometry; rank/allocate only after candidate generation. Do not use exact noun match or nearest-neighbor distance as universal hard gates.

**Supporting-context rule.** Retain unnamed objects when they complete a relation constraint, disambiguate seed instances, provide answer evidence, or occupy a reserved diversity/context slot. For directional relations, delay hard pruning until PoseAlign-T.

**Expected benefit.** Better QA-vs-object-budget Pareto frontier than seed-only, KNN, and grounding-oriented pruning while avoiding full-scene rendering.

**Difficulty.** Medium. V0 can be training-free using fixed GT object labels/boxes plus frozen text/VLM parsing. Main challenge is defining support utility without support-object GT.

**Data/metrics.** ScanQA and SQA3D downstream QA; Object Reduction Ratio; Question Entity Coverage; Context Benefit Rate; Support Ablation Sensitivity; QA-vs-object-budget curve. Supporting-Context Retention remains proxy-only unless an explicit annotation protocol is added.

**Compute.** Selector geometry is CPU/lightweight. Frozen <=7B VLM remains dominant VRAM cost. PruneGround's pruning/reformulation reference uses Qwen2.5-VL-3B; its full LLM-Grounder is trained and should not be transferred as the main method.

**Ablation.** Full scene vs seed-only vs Seed+KNN vs CAPruner vs PruneGround-inspired grounding pruning vs relation-aware support vs relation+diversity support vs +PoseAlign-T, all at matched object budgets K={5,10,20} where applicable.

**Risks.** No complete supporting-object GT in ScanQA/SQA3D; selector can discard global/context evidence; gains may collapse to a simple relation heuristic; PruneGround substantially narrows novelty.

**Publication potential.** Moderate if matched-budget experiments establish a repeatable gap between grounding-anchor utility and QA-support utility; weak if improvements are only from larger K or backbone changes.

## Novelty boundary update
The strongest defensible claim is now narrower: **QA-specific retention of named and unnamed supporting objects before Abstract3D rendering, under a strict object/render budget, evaluated directly on ScanQA/SQA3D.** PruneGround is now a stronger peer-reviewed baseline against generic spatial pruning and unnamed-anchor expansion.

## Top candidate this week
**SAFER-QA / QASER-Utility** remains #1. Reason: the EMNLP 2026 status of PruneGround increases evidence that pruning is useful but simultaneously makes generic pruning/anchor expansion prior art.
