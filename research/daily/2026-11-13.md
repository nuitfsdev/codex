Dataset is maritime, requires mapping/scene construction, not ScanQA; code, VRAM and venue not verified. Fixed ScanNet object IDs already avoid its core fragmentation problem. Secondary conceptual caution about consistent object identity across selected views; not a main candidate. https://arxiv.org/abs/2611.13903

### Candidate: Cross-View Witness Identity Audit (CWIA) — evaluation only
- **Hypothesis:** selected objects visible in multiple camera poses may be double-counted or mismatched by a 2D VLM, reducing multi-view QA reliability even with correct object selection.
- **Stage:** multi-view aggregation / evaluation after PoseAlign-T and selective renderer.
- **Selection rule:** reuse SAFER-QA scene-wide semantic + relation-aware candidate ranking; retain explicit named seed IDs and unnamed answer candidates within K, never exact-noun-only.
- **Supporting context:** preserve relation endpoints, competing same-class anchors and witness bundles; maintain stable instance ID/label across views. Never render all scene objects in main method.
- **Expected benefit:** diagnose count inconsistency and enable ID-consistent aggregation; no demonstrated accuracy gain.
- **Difficulty:** low–medium; training-free. CPU ID bookkeeping O(KM); additional VLM calls only for paired ablation. No extra selector GPU VRAM; end-to-end peak VRAM unmeasured, target 3B–4B quantized on T4 16GB.
- **Data/metrics:** ScanQA counting and relational subset; SQA3D secondary; EM/CIDEr, ORR=1-|S|/N, QEC, Answer-Witness Recall, Supporting-Context Retention (independent GT only), complete witness coverage, per-view ID consistency, latency, VRAM.
- **Ablations:** M=1 vs M=2; consistent IDs vs per-view re-numbered IDs; fixed K=10 and K={5,20}; same VLM/render/prompt budget; distinguish genuine multi-view gains from extra token cost.
- **Risk:** VLM may ignore labels, occlusion/cropping, weak independent support annotations; high context-loss risk at K=5, counting/negation require scene-wide completeness checks.
- **Publication:** low standalone; useful diagnostic for main SAFER-QA.
- **Scores (/5, Compute higher=cheaper):** Novelty 1.1; Expected Accuracy Gain 1.8; Feasibility 4.8; Compute 4.6; Fit 4.7; Evidence 3.2. Subjective prioritization, not measured.
