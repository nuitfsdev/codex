## Candidate A — Answerability-Aware Witness Completeness Audit (AAWCA; SECONDARY)
Hypothesis: separating *sufficient evidence for a selected object answer* from *global-scene completeness* improves reliability, especially counting/negation, at fixed K. Stage: question role parsing -> pre-render selector audit -> spatial verifier. Selection: fixed boxes/IDs; frozen semantic seed retrieval, scene-wide soft relation search for unnamed answer candidates; choose K by witness bundle utility; no exact-noun/KNN hard gate, NEVER render all objects in main method. Support rule: preserve competing answer instances, relation bridges, reference anchors; if global counting/negation cannot be certified from S, flag insufficient evidence rather than infer global absence. Expected benefit: fewer unsupported answers, not necessarily higher raw EM. Difficulty medium; training-free CPU O(N^2) pair geometry; selector ~0 incremental GPU VRAM, VLM T4 16GB target not measured. Evaluate ScanQA/SQA3D K=5/10/20 M=1: EM/CIDEr, coverage-conditioned EM, abstention/coverage, ORR/QEC/AWR, independent-GT SCR or explicit proxy, context loss, latency, peak VRAM. Ablate no gate vs typed gate vs oracle evidence sufficiency (evaluation only); report accuracy on ALL questions and answered subset. Risks: abstention can inflate selective accuracy; object labels leak answers; global counts require full object metadata but not full-scene rendering; relation parsing errors. Publication LOW standalone / MEDIUM only with matched-budget QA gain and evidence integrity. Scores N1.6 Gain2.6 Feas4.5 Compute4.7 Fit4.9 Evidence3.9. Context-loss HIGH K=5, counting/negation.

## Candidate B — Grounding Necessity Diagnostic (GND; EVALUATION ONLY)
Hypothesis: selected instance mesh + label overlays can create shortcuts that mask failure to use geometric evidence. Stage: structured reasoning/evaluation; keep same K objects and supports, never full scene render in method. Compare label+mesh vs mesh-only vs box-only vs label-only and perturbed spatial relations / identical-category distractors. Expected benefit: honest novelty/causal evaluation, no promised accuracy gain. Difficulty low-medium; no training, CPU perturbations plus sequential <=7B VLM inference; peak VRAM similar model load but unmeasured; extra inference time. Metrics EM/CIDEr, relation consistency, AWR/SCR inherited, latency, VRAM. Risk counterfactual validity, altered occlusion; independent GT needed. Publication LOW standalone. Scores N1.3 Gain1.2 Feas4.6 Compute4.3 Fit4.8 Evidence4.2.
