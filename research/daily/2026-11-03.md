## New candidate: Typed Witness Sufficiency Gate (TWSG) — secondary refinement, not standalone novelty
**Research hypothesis:** Explicit question-to-evidence obligations and deterministic completeness checks can avoid discarding unnamed answer/support objects while keeping |S|<=K and avoiding wasteful expansion. **Stage:** question parsing -> object selection -> spatial verification. **Object-selection rule:** parse roles (named seed, unnamed answer slot, relation endpoints, frame anchors, cardinality/negation), retrieve seeds by frozen semantics, score scene-wide unnamed candidates by soft relation and role compatibility, select complete witness bundles within K. **Supporting-context rule:** preserve unnamed answer objects, bridges, same-class disambiguators, competing candidates; do not exact-noun/KNN hard gate; counting and negative questions flagged when selected evidence cannot establish completeness. **Benefit:** fewer unsupported answers and avoidable context loss, NOT yet measured. **Training:** none V0. **Difficulty:** medium. **Compute:** CPU geometry O(N^2) worst case, negligible dedicated selector GPU VRAM; <=7B 4-bit VLM T4 16GB peak unmeasured. **Metrics:** ScanQA/SQA3D EM/CIDEr, ORR=1-|S|/N, QEC explicit seed recall, AWR unnamed answer recall, SCR only if independently labeled otherwise proxy, complete-witness rate, context-loss, abstention coverage/risk, latency/VRAM. **Ablation:** fixed K=10 M=1 semantic Top-K vs OpenSlotSoft vs RWC vs TWSG, parse off, sufficiency gate off, K=5/20; same renderer/VLM/prompt/calls. **Risk:** brittle parsing, false completeness, K infeasible for counting; abstention can inflate selective accuracy. **Publication:** LOW standalone given PEPS, potentially MEDIUM integrated if matched-budget QA gain + fewer witness losses.

## New candidate: Selected-Object Pose-Indexed View Ranking (SOPVR) — lower priority
**Hypothesis:** selecting cameras that jointly expose retained witness IDs and relation edges may improve QA per view. **Stage:** PoseAlign-T/view selection. **Selection:** unchanged SAFER-QA |S|<=K, rank candidate cameras via box projections/estimated relation observability on selected objects only; **support:** preserve all witness IDs; never use pre-render full-scene imagery. **Benefit:** better selected-view evidence; unmeasured. **Training:** none; CPU O(MNK) box projection (M candidate cameras); optional selected-mesh visibility checks. **Difficulty:** medium; GPU VRAM no additional model, actual rendering overhead unmeasured. **Metrics:** QA EM/CIDEr, witness visibility@M, relation coverage, latency, inherited ORR/QEC/SCR, context loss. **Ablations:** PoseAlign-T-only vs camera coverage vs relation-aware at M=1/2, same selected K. **Risk:** occlusion estimates and camera cropping; QGVI is retrieval on existing full-scene assets, not equivalent. **Publication:** LOW standalone.
