# Daily Proposal Research — 2026-09-11

## New evidence retained

### 3D visual grounding based on active perception — Complex & Intelligent Systems, published 2026-09-10
Peer-reviewed/open-access article (Liang Geng). It formulates 3D visual grounding as state-driven closed-loop grounding over reusable scene memory. The method maintains candidate/evidence state, predicts informative viewpoints, verifies candidates only in local projected regions, and uses explicit `resolved / ambiguous / missing / conflict` states to decide whether to stop, continue active perception, or backtrack. Evaluated on ScanRefer, Sr3D, Nr3D, and OpenTarget. No public code or explicit training requirement was found on the accessible article page during this run.

Novelty implication: fixed Top-K support expansion is not the only defensible design. Prior work now gives peer-reviewed evidence that adaptive evidence acquisition conditioned on ambiguity can reduce unnecessary full-scene reasoning. However, the paper is grounding-oriented, not ScanQA/SQA3D QA, and does not solve minimal object-subscene selection for open-ended answers.

## Candidate: UGSE — Uncertainty-Gated Support Expansion

**Research Hypothesis:** a QA selector should not allocate the same support-object budget to every question. Start with seed + minimal relation-compatible support and expand the Abstract-3D subscene only when the current evidence remains ambiguous, missing, or inconsistent. This can improve the QA-vs-object-reduction Pareto frontier compared with fixed Top-K support selection.

**Stage changed:** question-conditioned object/subscene selection immediately before PoseAlign-T / Abstract Renderer.

**Object-selection rule:**
1. Hard-retain resolved seed/referred objects.
2. Add a small initial support set from relation-aware geometry under budget K0.
3. Render only the current subscene and obtain structured answer/evidence state.
4. If state is `resolved`, stop.
5. If `ambiguous`, expand with the highest-scoring relation/diversity candidates that discriminate current alternatives.
6. If `missing`, broaden relation radius / co-visibility / semantic candidates.
7. If `conflict`, retain competing candidates and request an additional aligned view rather than immediately adding many objects.
8. Stop at Kmax or when answer/evidence becomes stable.

**Supporting-context rule:** unnamed support objects are acquired incrementally according to which uncertainty remains unresolved, rather than by unconditional Top-K expansion. Seed objects are never removed. Viewpoint-dependent left/right/front/behind filtering is deferred until PoseAlign-T.

**Expected benefit:** lower mean rendered-object count while preserving or improving QA; less clutter for easy questions; more context only for difficult/ambiguous questions.

**Implementation difficulty:** medium. Requires a deterministic state/stop criterion. Prefer answer consistency + symbolic geometry checks over raw VLM confidence, which is poorly calibrated.

**Data / metrics:** ScanQA and SQA3D; EM/CIDEr as applicable; Object Reduction Ratio; Question Entity Coverage; mean/median selected objects; expansion rate; QA-vs-object-budget curve; Context Benefit Rate; Support Ablation Sensitivity; Stop Correctness (`resolved` predictions that remain correct after oracle/full-scene comparison on analysis subset).

**Compute estimate:** selector/geometry negligible VRAM; <=7B VLM remains dominant. Iterative verification can increase VLM calls versus one-shot QASER, so compute efficiency depends on early-stop rate. No daily GPU benchmark performed.

**Required ablation:** fixed-budget QASER K={5,10,20} vs UGSE K0 small / Kmax matched; UGSE without relation-aware expansion; UGSE without PoseAlign-T; always-expand vs uncertainty-gated; state criterion from answer consistency vs geometry verification. Report accuracy at matched average object count and matched VLM-call budget.

**Risks:** VLM uncertainty is uncalibrated; iterative errors may snowball; extra VLM calls can erase rendering savings; active-perception grounding evidence may not transfer to QA. Avoid claiming closed-loop evidence acquisition itself as novel.

**Publication potential:** moderate. Stronger if the method demonstrates a superior QA/object Pareto frontier and fewer rendered objects than fixed-budget QASER at comparable VLM-call cost.

**Scores (1-5):** Novelty 3.0 standalone / 3.4 inside QASER; Expected Accuracy Gain 3.5; Feasibility 4.2; Compute Cost 3.6 (higher=cheaper); Fit 4.8; Evidence Strength 4.2.

**Object-selection diagnostics:** expected Object Reduction Ratio adaptive (target to test: 60-90% on easy questions, lower on difficult questions); Question Entity Coverage target >=95%; Supporting-Context Retention proxy-only; context-loss risk medium if stop state fires too early.
