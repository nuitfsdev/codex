# Daily Proposal Research — 2026-09-25

## New evidence
### From Alignment to Fusion in 3D Vision-Language (arXiv:2609.28222, submitted 2026-09-23)
- Status: arXiv preprint; no verified conference acceptance in today's primary-source scan.
- Method: triple pairwise cosine alignment across point/voxel/multi-view representations, prompt-guided task-conditioned query decoder, orthogonally constrained representation transforms, adaptive fusion.
- Evaluation includes ScanQA and SQA3D and reports improvements over PQ3D, but the method is learned and substantially outside the thesis's training-free 2D-VLM pipeline.
- Transferable insight: task-conditioned retrieval/fusion is stronger evidence than generic scene compression, but importing its learned fusion stack would violate the intended lightweight scope.
- Decision: evidence/novelty limiter only; do not promote to main candidate.

### CVP: Central-Peripheral Vision-Inspired Multimodal Model for Spatial Reasoning (WACV 2026)
- Peer-reviewed WACV 2026. Uses a trained target-affinity token for query-relevant object focus plus an allocentric grid for global scene context.
- Evaluates ScanQA and SQA3D; reported 107.1 CIDEr on ScanQA and 62.3 EM on SQA3D.
- Important novelty boundary: query-relevant object focus plus retained global context is already demonstrated. CVP is not lightweight transfer: its reported implementation builds on LLaVA-Video-7B and joint training across five datasets; secondary reporting states eight A100 GPUs.
- Transferable insight: local relevance and global context should be separated rather than collapsed into one Top-K score.

## Candidate refinement: QASER-DualBudget
Research hypothesis: under the same pre-render object budget K, explicitly splitting the budget into QA-evidence objects and a small global-context reserve will preserve QA better than pure relevance Top-K, while fixed GT boxes let this be done training-free.

Stage changed: question-conditioned object selection before PoseAlign-T / Abstract3D.

Object-selection rule:
1. Hard-retain explicit seed entities and unresolved same-class alternatives.
2. Generate scene-wide relation-compatible unnamed support candidates.
3. Allocate K_evidence slots using QA/relation utility.
4. Allocate K_context slots independently for non-redundant global context; context selection must not require proximity to the seed.
5. PoseAlign-T refines viewpoint-dependent directional relations; render only retained objects.

Supporting-context rule: an unnamed object may survive either because it completes/validates a question relation or because it occupies a bounded global-context slot. Exact noun match and KNN are not universal gates.

Expected benefit: reduces catastrophic context loss while retaining most of the rendering reduction; directly tests the central-vs-peripheral evidence split without CVP's training.

Difficulty: low-medium.
Compute: selector CPU/light GPU; dominant VRAM remains <=7B 2D VLM. No extra training required for V0.
Data/metrics: ScanQA/SQA3D; QA metrics; Object Reduction Ratio; Question Entity Coverage; QA-vs-object-budget; Context Benefit Rate; Support Ablation Sensitivity; proxy Supporting-Context Retention.
Ablation: pure relevance Top-K vs 90/10, 80/20, 70/30 evidence/context budgets at K={5,10,20}; compare Full, Seed-only, KNN, SemanticTopK, CAPruner, PruneGround-inspired selection, QASER-Utility; +PoseAlign-T.
Risk: global-context slots may waste scarce K on small budgets; context GT is incomplete, so downstream QA must remain the primary criterion.
Publication potential: moderate only if dual-budget selection gives a stable Pareto improvement at matched K.

Scores (1-5): Novelty 3.0 standalone / 3.4 integrated; Expected Accuracy Gain 3.8; Feasibility 4.8; Compute Cost 4.9 (higher=cheaper); Fit 5.0; Evidence Strength 5.0.
Targets, not claims: ORR 50-85%; QEC >=95%; Supporting-Context Retention proxy-only; context-loss risk medium-low relative to pure Top-K.

## Novelty update
Do not claim query-relevant object focus, central/peripheral context separation, task-conditioned retrieval, or global-layout context as standalone novelty. The defensible thesis claim remains QA-specific pre-render retention of named seeds plus unnamed supporting objects under a strict object/render budget, using fixed object annotations/3D boxes.

## Top candidate this week
SAFER-QA / QASER-Utility remains #1. QASER-DualBudget is a refinement, not a replacement. It is currently the strongest low-cost context-preservation ablation because CVP provides peer-reviewed ScanQA/SQA3D evidence that query-focused object evidence and global scene context contribute differently, while the thesis can test the same principle training-free at object-selection time.
